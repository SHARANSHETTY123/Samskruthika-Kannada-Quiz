# Samskruthika Kannada Quiz — GitHub Pages

GitHub-ready static MCQ website containing exactly **455 questions** extracted from the two supplied Excel files.

## Included
- `index.html` — responsive quiz UI
- `questions.js` — all 455 questions, four options, and answer key data
- `README.md` — deployment instructions

## Features
- Start form with name and question-range selection
- Q1–455 question bank
- Correct/wrong answer highlighting after selection
- Score and percentage
- Answer review
- Question navigator
- Previous/Next navigation
- Browser localStorage for progress
- Mobile-friendly GitHub Pages design

## Publish on GitHub
1. Create a new GitHub repository.
2. Upload `index.html`, `questions.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and open the GitHub Pages URL.

## Answer-key note
The supplied scanned answer-key pages were used where they contain explicit answer entries. For ranges where the supplied files did not expose an explicit answer entry, the answer was derived from the supplied question/options rather than invented as a placeholder.
